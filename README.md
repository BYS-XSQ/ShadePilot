# ShadePilot

ShadePilot 是一个轻量的 Windows 显示体验调节工具，只通过 `Dxva2.dll` 调用显示器 DDC/CI。

## 当前功能

- 枚举物理显示器；
- 探测并显示亮度、对比度、色温能力；
- 探测标准 MCCS `VCP 0x8A` 硬件饱和度，支持时显示实时滑块并纳入预设与重置；
- 硬件色温不受显示器支持时隐藏空下拉框，并引导使用画面风格的连续色温；
- Windows 高层色温能力缺失时，回退读取标准 MCCS VCP `0x14` 色彩预设；
- 当 Windows 高层能力查询失败时，使用白名单 VCP 0x10/0x12 回退读取亮度和对比度；
- 写入时优先使用标准 VCP，并在写入后回读确认；显示器静默忽略时会直接提示；
- 亮度和对比度滑块默认实时应用，带 180 ms 防抖，松开鼠标时立即提交最终值；
- DDC/CI 通信在后台串行执行，连续拖动时合并中间值，避免阻塞界面；
- 实验性的 SDR 暗部提升与高光压缩曲线，强度范围 0–100，提供推荐预设和原始 Gamma 恢复；
- 冷蓝—暖黄的色温控制与偏绿—洋红的色调控制；
- 电影感、蓝调、轻松氛围、清晰夜景和柔和原色预设；
- 可将当前参数保存或覆盖为自定义画面风格；
- 每个画面风格以及“恢复原始画面”都能独立设置 Ctrl/Alt/Shift 与数字、字母或 F1–F12 组合；
- 最小化后隐藏到系统托盘，快捷键在后台继续工作；
- 所有参数滑块忽略鼠标滚轮，避免滚动页面时误改画面；
- 圆角面板、按钮和数值胶囊使用 GDI+ 抗锯齿矢量路径绘制，并启用 Per-Monitor V2 DPI 感知；
- 内置雾紫、极夜蓝、薄荷灰、暖砂和黑白极简五套 UI 主题，支持即时切换并记忆选择；
- 手动应用受支持参数；
- 按显示器保存本地预设；
- 一键或退出时恢复启动前状态。

## 安全边界

程序不查找、不打开、不读取《逃离塔科夫》或其他游戏进程；不注入 DLL，不创建画面覆盖，不截图，不模拟输入。它只调用 Windows 的显示器配置 API。

## 运行

双击 `bin\DisplayPreset.exe`。常规运行不需要管理员权限。

如果显示器未出现或控件显示“不支持”，请确认显示器菜单中的 DDC/CI 已开启。笔记本内屏、某些扩展坞、KVM 或转接器可能无法使用这套接口。

默认勾选“拖动时实时应用”，拖动亮度或对比度滑块即可看到变化；“重新应用全部”可用于重试全部参数。默认勾选“退出时自动恢复”。

“暗部/高光（实验）”使用 Windows 全局 Gamma Ramp，作用于整个 SDR 桌面，不读取游戏画面。它在 HDR 下可能不生效；主窗口退出时会随“退出时自动恢复”一起恢复。

界面采用紫色主调的统一圆角控制面板，内部用浅紫背景和留白划分功能区。显示器控制、画面风格、预设和恢复位于同一滚动页面；画面风格无需打开第二个窗口，可直接选择预设或调整四项参数。

## 构建

在 PowerShell 中运行：

```powershell
.\build.ps1
```

该脚本使用 Windows 自带的 .NET Framework C# 编译器，不下载第三方依赖。
